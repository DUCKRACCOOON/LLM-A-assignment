## AI 실행과 실험 조건

- 기존 서버의 Meta-Llama-3-8B-Instruct, BF16, greedy, GPU 0을 사용했다.
- 탐색 알고리즘은 CPU에서 순차 실행했고 시간은 방법 순서를 섞은 5회 중앙값이다.
- R2 프로그램 제안 12개 중 8개가 유효했고, 서로 다른 가중치는 2개였다.

- 검증 기준에 따라 R3 최종 평가의 추가 LLM 생성은 하지 않도록 결정했다.
  규칙·무작위 대조군과 R1·R2 진단 평가, 확대·재사용 평가의 완료 여부는 확인 중이다.
- 유료 API 호출은 없다. 생성 로그·토큰·시간의 최종 합계는 서버 파일 회수 후 확정한다.
- 최초 실행에서 발견한 LPA 종료 조건의 부동소수점 문제를 수정하고,
  중간 크기 지도 600문제 회귀검사를 추가했다. 이전 실행 결과를 재사용하지 않고
