확장성 평가 일부가 미완료인 부분 보고서입니다. OpenAI API가 credit_balance_exhausted / insufficient_quota를 반환해 실험 2 확장성 평가 중 실행이 중단됐습니다. 실험 3은 이미 저장된 응답·실행 기록으로 추가 API 호출 없이 재생 평가했습니다. 아래 본 평가 표는 세 실험의 완료된 1,000문제 전체 결과이며, 실험 2의 미완료 확장성 사례를 성공한 것으로 처리하지 않았습니다.

완료된 본 평가에서의 해석

실험 1: 경유점 정제는 기존 LLM-A*보다 연산량을 줄였지만, GPT 경유점 없는 g+2h 대조군보다 연산량이 낮지는 않았습니다. 개선의 일부를 잘못된 GPT 안내를 배제하는 효과로 해석할 수 있으며, GPT 안내의 추가 기여가 입증됐다고 주장하지 않습니다.

실험 2: 오류 피드백으로 GPT 자체 출력의 유효율은 상승했지만, 같은 호출 횟수의 비구체적 재검토 대조군 대비 최종 탐색 성능은 일관되게 좋아지지 않았습니다. 출력 품질 개선과 최종 탐색 성능 개선을 구분해야 합니다.

실험 3: 최초 응답 수집 때 저장한 조건부 호출 실행 기록과, 동일 응답을 사용하는 재생 결과가 연산량·저장량·길이·유효성·전체 경로·경유점·호출 시점·호출 횟수에서 일치함을 확인했습니다. 호출 수는 프롬프트별 Few-shot 498/1000, CoT 498/1000, RePE 498/1000입니다. API 사용량과 탐색 성능을 별도로 비교해야 합니다.

실행 순서의 예외: 크레딧 부족으로 실험 2 확장성이 중단된 후, 추가 요청이 필요 없는 실험 3 재생을 먼저 마쳤습니다. 고정된 조작변인·입력·평가 규칙은 변경하지 않았습니다. 원래 계획의 모든 단계가 순서대로 완료됐다고 주장하지 않습니다.

모델 gpt-3.5-turbo-0125, temperature=0, max_tokens=1000, 최초 프롬프트·지도·경계·충돌 판정·탐색 규칙을 유지했습니다. 새 최초 응답을 실험군과 대조군에서 공유했습니다. 사용자 요청에 따라 실행 호스트는 Windows에서 Linux 서버로 이동했고, 기존 재현의 A*·Dynamic Weighted A*·g+2h 지표 3,000건과 일치함을 확인했습니다. GPT 추론은 API에서, 탐색은 서버 CPU에서 실행했습니다.
