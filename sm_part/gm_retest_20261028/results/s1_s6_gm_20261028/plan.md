기존 GM의 실제 case 파일을 그대로 가져와 문제 목록·입력 내용·해시를 고정한다. 같은 seed로 임의 재생성해 동일 데이터라고 부르지 않는다. 앞서 잠정 제안했던 신규 600문제·세 프롬프트 구성은 사용자 지시에 따라 이 GM 구성으로 대체한다.

S4는 기존 지도 단위 분할을 유지한다: 학습 50지도/500문제, 검증 10지도/100문제, 보정 예약 20지도/200문제, 평가 20지도/200문제. 보정 예약 집합은 이번 학습에 사용하지 않는다. 예시 지도 0·2·3·4·5는 학습 집합에만 속한다.

공개 평가 지도 ID는 `96,16,56,21,34,42,68,57,88,51,87,26,61,77,84,76,58,41,45,46`이다. S6의 새 점수 설정 선택도 학습·검증 집합만 사용하고 해당 목록과 별도 30·120문제로 설정을 선택하지 않는다.

**S1~S6 공통 비교의 핵심 표는 공개 평가 200문제, 별도 30문제, 합성 120문제의 세 표**로 작성한다. 공개 전체 1,000문제 표에는 학습·설정 선택에 노출된 지도 여부를 표시하고, S4·S6의 일반화 평가로 해석하지 않는다. 세 집합을 합친 350문제 수치는 보조 정보로만 사용한다. 학습과 평가의 지도 해시 중복을 검사한다. 과거 연구에서 이미 관찰한 자료이므로 연구 전체의 완전한 미관측 평가라고 표현하지 않는다.

## 4. 공통 문제·파서·경로 검증

- 정수 격자의 8방향 이동, 축 비용 1·대각 비용 √2. 외곽 좌표는 벽이고 유효 경로는 내부에 있어야 한다.
- GM의 선분 장애물 충돌 판정을 기준으로 교차·끝점 접촉·벽 위 이동·경계·퇴화 벽을 통일한다. 별도의 corner-cutting 규칙을 임의 추가하지 않는다.
- 원 LLM-A*의 파서·경유점 필터·전환·tie-break·CLOSED 동작은 GM 원본 동작으로 고정한다. S1~S3에는 필요한 개입만 적용한다.
- 다른 탐색기를 쓰는 S4~S6은 큐·재개방 규칙을 문서화하고 동일 그래프를 푸는지 차등 검증한다. 원 논문 재현과 개선 구현을 구분한다.
- 모델의 좌표 제안 유효성과 최종 격자 경로 유효성을 각각 측정한다. 최종 경로는 시작·목표, 정수 좌표, 단위 8방향 이동, 모든 선분 충돌을 독립 검증한다.
- 독립 선분 그래프의 Dijkstra로 최적 길이 L*를 얻는다. 정답은 평가·S4 학습 라벨 생성에만 쓰고 평가 중 탐색 입력으로 넘기지 않는다.

## 5. 방법별 실험과 대조군

| ID | 구현 범위 | 직접 비교 | 필수 검증 |
| --- | --- | --- | --- |
| S1 | 중복·왕복 제거, 충돌 없는 단축, 최종 유효성 검사 | 같은 탐색기의 V-Gate-only, 원 LLM-A*, g+2h | 유효성 검사만 한 효과와 정제의 추가 효과 분리; 파싱·정제·충돌 검사 시간 포함 |
| S2 | 최초 제안이 무효일 때 구체적 오류로 정확히 한 번 수정 | 오류 없는 일반 재검토 S2-control, 최초 응답 원 LLM-A* | 두 수정 조건의 호출 기회 동일; 두 번째 답 무조건 채택; 실패 응답 재생성 금지 |
| S3 | g+2h로 시작해 정체 때 최대 한 번 안내 삽입 | 즉시 안내 원 LLM-A*, 끝까지 안내 없는 g+2h | 기존 g/parent/CLOSED/OPEN 유지, 호출 전후 pop 합산, OPEN 재계산 계측 |
| S4 | 기존 소형 TransPath-inspired 모델의 경로 확률로 FOCAL 안내 | 같은 FOCAL의 안내 없음, 학습 전 네트워크, A* | 동일 학습·검증 분할, seed 11/22/33, 검증 손실로 checkpoint 선택, 평가 자료 선택 금지 |
| S5 | 정확한 직사각형 sparse 압축·원 격자 경로 복원 | 같은 그래프 기반 A*_octile, 공통 A*·g+2h·K3 | L=L*, 경로 복원, 압축·삽입·macro edge·fallback 비용 포함 |
| S6 | 일부 벽으로 정확 탐색→전체 벽 검증→충돌 벽 추가 | rule, 같은 초기 벽 수의 random, 전체 벽 A*_octile | 매 완화 풀이의 정확성, 최대 4회, 마지막 전체 벽 fallback, 모든 회차 합산 |

S1의 V-Gate-only는 정제 조건과 동일한 파싱·경유점 정규화 및 최종 검사 규칙을 적용하되, 왕복 삭제·단축만 하지 않는다. GM의 기존 V-Gate와 이 통제 조건이 다르면 둘을 별도 이름으로 보존한다.

S2는 최초 응답에서 고정 검증기가 찾은 첫 오류만 전달한다. 일반 재검토에는 오류 세부정보 대신 `Not provided.`를 제공한다. 호출 순서를 문제 ID로 결정적으로 교대한다. 최초 유효 응답은 두 조건 모두 추가 호출 없이 그대로 쓴다.

S3 정체 조건은 기존 S3를 유지한다: `max(10, ceil(d0))` pop마다 검사하고 최소 목표 거리의 개선이 `0.05*d0` 미만이면 한 번 호출한다. 새 상태 정보를 프롬프트에 추가하지 않는다. 새 최초 응답을 고정해 재생하므로 논리적 호출 절감과 실제 독립 온라인 지연 측정을 구분한다.

S4의 주 품질 제한은 GM의 5% 조건과 맞춘 **FOCAL w=1.05**로 정한다. 기존 S4의 w=1.1과 다른 설정임을 명시하며, 필요하면 w=1.1을 보조 조건으로만 추가한다. 네트워크는 기존 7채널·160,297 파라미터 구조, AdamW lr=0.001·weight_decay=0.0001·batch 32·60 epochs를 유지한다. 모델 로딩·학습·정답 생성은 별도 비용으로 남긴다. 공식 TransPath 재현이라고 주장하지 않는다.

S5 주 변형은 기존 sparse로 고정하고 본 평가 결과에 따라 full로 바꾸지 않는다. S6는 기존 program의 네 특징(직선 교차, 정규화 벽 길이, 우회 거리, 경계 부착)을 유지한다. GM 모델로 새 가중치 후보 최대 12개를 제안받는다. 각 가중치는 [-2,2]의 유한 수이며, 같은 가중치 중복 제안은 생성 비용을 모두 기록하고 계산만 공유한다. 학습 집합의 A*_octile 대비 heap-pop 비율 기하평균으로 상위 3개를 고른 뒤 검증 집합의 같은 기준으로 한 후보를 고정한다. 동률은 제안 번호 순서로 결정한다. 시간 잡음으로 후보를 고르지 않으며 실제 전체 시간 이득 여부는 별도 평가한다. 자유 코드 생성·실행은 하지 않는다. 과거 Llama 제안 `[0.5,0.3,0.1,0.1]`은 별도 역사적 비교 조건으로 표시한다. 제안 형식 오류도 보존하며 좋은 응답으로 재생성하지 않는다. 새 후보를 확보하지 못하면 S6 rule과 기존 고정 program을 구분해 보고하고 새 제안 실험 완료로 표시하지 않는다.

공통 비교군은 GM A*_Euclidean, 고정 g+2h_Euclidean, 원 LLM-A*, GM V-Gate, K3 직선거리+벽, K3 octile+벽이다. S4의 동일 FOCAL 대조군과 S5/S6의 동일 백엔드 A*_octile을 추가한다. 고정 g+2h를 Dynamic Weighted A*라고 부르지 않는다.

## 6. 계측과 통계

| 항목 | 정의 |
| --- | --- |
| operation | **모든 실제 heap pop 합계**, 중복·stale·다중 큐·S6 모든 회차 포함 |
| successor_expansions | 실제 이웃 순회를 실행한 횟수, 목표에서 종료한 선택은 제외. 중복 확장과 고유 확장을 별도 기록 |
| storage | 기존 규약의 g 사전 크기(무한 값 포함 여부 명시). 배열 기반·반복 탐색은 할당량/발견 노드/동시 peak를 별도 기록; 전체 RAM으로 해석하지 않음 |
| 관리 비용 | heap push·rekey scan·heapify·버린 항목·FOCAL 스캔·충돌 검사·복원·fallback |
| 계획기 시간 | 파싱·정제·그래프/압축 준비·S4 추론·모든 탐색/재탐색·필수 경로 검증 포함 |
| 제외·별도 비용 | 파일 IO·로그·통계·독립 정답 평가. 학습·라벨 생성·모델 로딩·API 지연·토큰은 별도 공개 |
| 경로 품질 | 성공률, L/L*, 최단 비율, 5%/10% 초과율, 최악 초과, 길이의 실제 분모 |

각 문제에서 모든 방법의 순서를 고정 난수로 섞고 한 프로세스에서 순차 실행한다. 매 시행 그래프·이웃·충돌 캐시를 초기화하며 초기화 자체는 측정 밖에 둔다. S4는 상주 모델 추론 시간을 주 표에 쓰되 로딩·warm-up 시간을 별도로 남긴다. CPU 스레드 수·전원 및 장비 상태를 기록하며 학습과 시간 측정을 동시에 실행하지 않는다.

5회 시간 중앙값을 문제별 대표값으로 사용한다. 같은 응답으로 반복 측정하는 5회는 LLM 독립 반복이나 표본 5배가 아니다. S4 세 학습 시드는 각각 보고하고, 공통 요약은 문제별 시드 산술평균으로 집계한 뒤 문제별 상대 비율을 기하평균한다.

대응 양수가 있는 지표는 `exp(mean(log(method/baseline)))`로 계산한다. 0인 카운터에 임의로 1을 더하지 않고 영점 건수·차이·분모를 별도 기록한다. 실패·timeout은 전체 성공률과 비용 분모에 남기며, 길이의 대응 비교는 양쪽 유효한 교집합과 누락 건수를 명시한다. 지도 전체를 묶어 재표집하는 2,000회 bootstrap 95% 구간은 탐색적 구간이며 다중 비교 보정된 전체 순위 근거로 쓰지 않는다.

S4는 L≤1.05L*, S5/S6는 L=L*를 전 문제에서 검증한다(절대 오차 1e-8, 상대 오차 1e-10). S1~S3·원 LLM-A*·g+2h·K3에는 동일한 품질 보장이 없으므로 유효성·길이를 함께 보고한다. 정확 탐색·5% 제한·제한 없는 방법을 단일 연산 수로 순위화하지 않는다. 개선/동일/악화 건수와 가장 악화된 사례를 보존한다.

## 7. 새 응답과 비용 규모

- 서로 다른 입력 1,150개 × standard 1종 = 최초 응답 **1,150건**.
- 최초 무효 응답 수를 I라 하면 S2 추가 응답은 **2I건**, 최대 2,300건.
- 온라인 생성 본체 합계 **1,150+2I ≤ 3,450건**. 파일럿은 이 안에 포함된다.
- S6 오프라인 점수 제안은 최대 **12건**을 별도 집계한다. 기본 설계의 모델 응답 수 상한은 **3,462건**이며 전송 재시도는 별도 기록한다.
- 5회 시간 반복·S4 세 시드마다 응답을 새로 생성하지 않는다.
- 요청 body·model·프롬프트·응답·토큰·지연·finish_reason·해시·실제 청구 관련 usage를 저장한다. API 키는 저장하지 않는다.
- 기존 응답은 역사적 연결 검사에만 사용한다. 이번 요청과 해시가 일치하는 **이번 실행의** 캐시만 재개 시 재사용한다.
- 금액은 실제 사용 가능 모델·단가·입력 토큰을 확인한 뒤 산출한다. 확인되지 않은 가격으로 예산을 단정하지 않는다. 쿼터·모델 접근 오류는 해당 수집을 중단하고 실패 상태를 남긴다.
- 실제 수집 호출 수와 방법을 단독 배치할 때 필요한 논리 호출 수를 별도로 제시한다. 새 API 지연을 캐시 재생 시간에 더한 값은 추정값이며 독립 온라인 벤치마크라고 부르지 않는다.

## 실행 전·파일럿 수정 이력

- Python 패치 버전은 3.11.18, CPU용 PyTorch 2.7.1, NumPy 1.26.4, SciPy 1.15.3, Shapely 2.2.0으로 구성했다.
