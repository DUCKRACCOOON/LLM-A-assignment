1,150문제 × 22조건 × 5회 = 126,500회 계측. 새 GPT-4o mini 응답 3,222건.
최종 경로 무효 및 선언한 품질 상한 위반은 모두 0건이다.
현재 AMD Ryzen 5 9600X CPU에서 모든 대조군을 함께 재측정했다.
GM 과거 Intel 장비의 절대 시간과 직접 비교하지 않는다.

## 해석 범위

- S1~S6의 기존 결과와 기존 추천·순위는 현재 평가 근거로 폐기한다.
- 새 결과는 학습·설정 선택과 분리된 공개 평가 200문제, 별도 30문제,
  GM seed의 합성 120문제를 구분한다. 공개 전체 1,000문제는 보조 결과다.
- 이 재실험은 18개 방법 전체의 동일 환경 재실험이 아니다.
- 보고서의 주 비율 분모는 g+2h이며, 직접 대조군도 별도로 제시한다.
  원 LLM-A* 기준 해석은 같은 문제의 B_llm 행에 대응시켜 다시 계산해야 한다.
- 기록된 계획기 시간은 API 지연을 제외한다. 저장 API 시간과 합친 값은
  서비스 전체 시간을 직접 반복 측정한 결과가 아닌 재구성 추정치다.
- S6 코드블록 파서 변경, 선택 비용 재계측 등 편차는 원자료와 함께 공개했다.

## 복원과 검증

이 폴더를 프로젝트 루트로 사용한다. 코드·입력·응답·학습 가중치·126,500회
계측 결과를 압축 없이 모두 제공한다. 원본 파일의 바이트는 변경하지 않았다.
`publication_manifest.json`은 공개 사본의 크기·SHA-256 목록이다.

Python 3.11 환경에 NumPy 1.26.4, SciPy 1.15.3, Shapely 2.2.0,
PyTorch 2.7.1+cpu를 설치한 후 아래처럼 검증할 수 있다.

```powershell
python experiments/s1_s6_gm_20261028/report.py verify
```

이 명령은 저장 결과만 검증하며 API 호출이나 탐색 재실험을 하지 않는다.
새 응답을 만드는 collect/programs generate 명령은 실제 API 호출을 발생시킨다.
비밀키·가상환경·캐시는 포함하지 않았다. 원 실행의 절대 경로와 Git 외부 소스
식별 해시는 역사적 메타데이터이므로 그대로 보존한다.
