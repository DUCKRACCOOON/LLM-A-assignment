# S1 계획서 · GPT 경유점 정제

## 목적과 문서 성격

기존 실행 `E1`의 고정 계획을 [프로토콜](../../results/improvements/protocol.json)과 [실제 코드](../../reproduction/improve_core.py)의 `refine`에서 정리했다. 2026-10-25 새 사전등록을 한 문서는 아니다. [현재 분담](../../docs/팀_개선방법_실험_분담.md)이 추가로 요구하는 확인 사항은 마지막 절에 구분한다.

가설은 GPT가 제공한 경유점의 중복·왕복·불필요한 우회를 줄이면 기본 LLM-A*의 탐색량을 줄일 수 있다는 것이다. GPT 자체의 품질 향상과 잘못된 안내를 제거하는 효과를 구별한다.

## 기존 실행 설계

1. 최초 응답을 기본 LLM-A* `B`와 공유하고 원래 파싱 및 경유점 처리 규칙을 적용한다.
2. 이미 방문한 좌표가 다시 나오면 그 좌표 이후의 왕복 구간을 시간 순서대로 지운다.
3. 현재 점에서 충돌 없이 직접 연결 가능한 가장 뒤의 점을 선택해 중간 경유점을 생략한다.
4. 정제한 경로 전체를 원래 검증기로 검사한다. 실패하면 내부 경유점을 사용하지 않는다. 최종 이동 경로는 기존 8방향 격자 탐색이 계산한다.

변경은 경유점 정제에 한정한다. `B`는 최초 경로를 그대로 사용하는 대조군, `N`은 GPT 경유점 없는 `g+2h`, `A`는 A*다. E2·E3와 결합하지 않는다.

| 항목 | 고정 조건 |
| --- | --- |
| 입력 | `vendor/llm-astar/dataset/environment_50_30.json`, 100지도·1,000문제 |
| 개발 | pilot 10문제 |
| 본실험 | 1,000문제 × standard(Few-shot)·cot·repe |
| 확대 | seed 240702511로 고른 10문제 × 좌표 배율 1~10, standard |
| GPT | gpt-3.5-turbo-0125, temperature 0, max_tokens 1000 |
| 이동 | 기존 8방향 격자, 축 이동 1·대각 √2, 기존 선분 충돌 규칙 |
| 지표 | 중복 포함 heap-pop `operation`, `len(g)` 저장량, 반환 길이, 유효성 |

문제별 A* 대비 비율과 B 대비 대응 비율의 기하평균을 사용한다. 정제 시간은 `preprocess_seconds`로 별도 기록한다. heap-pop 감소를 모든 전처리 연산 또는 실제 시간의 감소로 바꾸어 말하지 않는다. 독립 미관측 분할은 없고 기존 주 집계의 탐색량·시간에 신뢰구간을 산출하지 않았다. 경로 정확도의 탐색적 구간은 [후속 보조 분석](../../results/path_accuracy/report.md)에 별도로 있다.

## 실행과 근거 보존

원 실행은 Linux/Python 3.12.3에서 수행했다. GPT는 API, 탐색은 CPU이며 [환경 파일](../../results/improvements/environment.json)의 패키지 버전이 기준이다. `sm_part`를 작업 디렉터리로 두고 자료를 복원한 뒤 보고서를 재생성하는 명령은 다음과 같다.

```text
python reproduction/improve_run.py report
```

새 응답을 수집하는 기존 CLI는 `python reproduction/improve_run.py all --workers 8`이다. 입력받은 API 키를 사용하며 비용이 발생할 수 있는 재실험 명령이다. 이번 자료 정리에서 실행하지 않았다. 입력·캐시·원본 결과는 보존하고 재실험은 별도 복사본에서 수행한다.

## 현재 분담 기준의 미완료 확인

분담은 **V-Gate의 유효성 검사만 적용한 대조군과 정제의 추가 효과를 분리**하도록 요구한다. 기존 E1 묶음에는 동일 탐색기·동일 문제·동일 프롬프트의 V-Gate-only 독립 arm이 없다. 다른 `candidates_v1`의 `VGATE_STANDARD`는 FOCAL 기반이고 표본도 달라 E1의 직접 대조군으로 사용할 수 없다. 따라서 B·N 대비 결과는 제출할 수 있지만, 정제가 단순 유효성 검사보다 낫다는 결론은 현재 자료로 확정하지 않는다. 필요 시 이 비교만 별도 보완 계획으로 수립한다.
