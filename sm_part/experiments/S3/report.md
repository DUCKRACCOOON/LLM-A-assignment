# S3 결과 보고서 · 탐색 정체 시에만 GPT 호출

**본실험의 논리 API 호출을 50.20% 줄였으며 기본 LLM-A*보다 heap-pop도 감소했다. GPT 없는 g+2h보다 탐색량이 적지는 않았다.** 기존 `E3`, 완료일 2026-10-14의 결과다.

## 본실험과 호출 전후의 총량

프롬프트별 1,000문제 중 **498문제**에서 호출했고 502문제는 호출 없이 종료했다. 호출 전 탐색을 버리지 않고 이후 계산에 합산한 결과다. 아래 연산·저장·길이는 A* 대비 문제별 비율의 기하평균(%)이다.

| 조건 | 연산 % | 저장 % | 길이 % | 유효율 % | 논리 API 호출 |
| --- | ---: | ---: | ---: | ---: | ---: |
| N: g+2h | 34.32 | 56.23 | 102.02 | 100 | 0 |
| B: Few-shot | 39.45 | 60.54 | 102.22 | 100 | 1,000 |
| E3: Few-shot | 35.89 | 57.80 | 102.01 | 100 | 498 |
| B: CoT | 56.28 | 74.22 | 102.79 | 100 | 1,000 |
| E3: CoT | 39.38 | 62.16 | 102.21 | 100 | 498 |
| B: RePE | 75.31 | 88.54 | 102.44 | 100 | 1,000 |
| E3: RePE | 42.56 | 65.70 | 102.05 | 100 | 498 |

E3/B heap-pop 감소율은 Few-shot **9.01%**, CoT **30.03%**, RePE **43.50%**다. 근거는 [본실험 표](../../results/improvements/report/main_table.csv)와 [대응 비교](../../results/improvements/report/paired_comparisons.csv)다. 호출 전까지 프롬프트와 무관한 같은 탐색을 하므로 호출 문제 수가 세 프롬프트에서 같은 것은 별도 3회 독립 증거가 아니다.

## 확대와 해석

standard 100개 확대 조건에서 **75번 호출**해 B보다 25% 줄였다. A* 대비 연산·저장·길이 비율은 **31.49%·40.69%·103.50%**, 유효율은 100%다. B 대비 연산은 **18.87% 감소**했지만 N의 연산 비율 **23.05%**보다는 크다. [확대 표](../../results/improvements/report/scaling_table.csv)에 전체 조건을 보존했다.

호출 절감은 확인됐으나 GPT의 추가 안내가 N보다 유익하다는 근거는 없다. 정체 조건은 목표까지의 거리 개선만 보므로 올바른 우회도 호출을 유발할 수 있다. 반환 경로가 모두 유효한 것과 최단인 것은 다르다. OPEN 재계산과 API 비용까지 모두 heap-pop에 반영된 것도 아니다.

## 실행 순서 예외와 검증

API 크레딧 소진 뒤 E3를 이미 수집한 응답과 실제 호출 시점 trace로 먼저 재생 완료했다. 계획 순서와 다른 사실은 [실행 예외 감사](../../results/improvements/execution_deviation.json)에 보존했다. 최종 결과는 최초 수집 당시 경로·지표·trigger·호출 여부와 대조했다. 캐시 읽기 시간을 온라인 추론 시간이라고 사용하지 않는다.

S1~S3 전체의 28,270행·실제 응답 수집 8,814건은 공유 묶음의 수치다. [서버](../../results/improvements/verification.json) 및 [로컬 검증](../../results/improvements/local_import_verification.json)을 근거로 정리했다. 위 탐색량·시간 주 집계에는 신뢰구간이 없고 독립 미관측 검증·실제 서비스 응답시간 우위도 확인하지 않았다. 경로 정확도의 탐색적 구간은 [후속 보조 분석](../../results/path_accuracy/report.md)에 별도로 있다. 최초 구현·실험은 승민의 기여이고 이번 작업은 기존 자료 문서화다.
