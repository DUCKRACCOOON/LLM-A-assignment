S1~S3 묶음은 28,270 평가 행, S4가 속한 후보 묶음은 4,100행, S5~S6가 속한 후속 묶음은 43,520행과 별도 octile 보조 1,200행의 기존 검증 기록을 포함한다. 이는 각 방법 하나의 표본 수가 아니라 대조군·다른 후보를 포함한 묶음 전체 행 수다.

K1(위상 안내), K2(Conformal), J1(CHOMP), J2(Fast Marching)의 자료도 공유 패키지 안에 보존했다. 분담표의 최초 실험자와 최종 담당자를 바꾸지 않았다. 이 자료 정리는 팀 최종 채택이나 공통 조건의 전체 비교 완료를 뜻하지 않는다.

새 실험·유료 API 호출은 하지 않았다. 이번 확인은 자료 수집, 압축파일·원본 해시 검증, 기존 오프라인 코드 테스트와 문서 연결 점검이다. [복원 안내](archives/README.md)를 따르면 개별 원자료를 원래 경로로 복원할 수 있다.
