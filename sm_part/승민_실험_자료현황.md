# 승민 담당 실험과 자료 현황

현재 범위는 [팀 분담표](docs/팀_개선방법_실험_분담.md)의 S1~S6 여섯 방법이다. 아래 항목은 해당 분담표와 [공통 기준](docs/공통_실험_기준.md)을 모아 정리한 것이며, 새로운 실험 결과나 확정하지 않은 실행 설정을 추가하지 않았다.

## 담당 실험과 확인할 비교

| ID | 실험 | 정리·검증할 내용 |
| --- | --- | --- |
| S1 | GPT 경유점 정제 | 중복과 불필요한 왕복 제거, 충돌 없이 직접 연결 가능한 중간점 생략. V-Gate 유효성 검사만 적용한 대조군과 정제의 추가 효과를 구분한다. |
| S2 | 구체적인 오류 피드백으로 경로 수정 | 충돌·범위·좌표 오류와 그 위치를 GPT에 제공해 한 번 수정한다. 수정 전후 결과와 두 번째 호출 비용을 함께 남긴다. |
| S3 | 탐색 정체 시에만 GPT 호출 | g+2h로 탐색하다 정체 조건을 만족할 때 호출한다. 정체 판정, 이전 탐색 기록 재사용, 호출 전후 전체 연산량을 설명한다. |
| S4 | TransPath 계열 모델로 유망한 경로 영역 예측 | 실제 모델·학습 방식과 학습/평가 지도 분리를 명시한다. 간단한 모사 구현과 원 TransPath 전체 재현을 구분한다. |
| S5 | 빈 공간을 압축하는 정확한 탐색 | 합법적 격자 이동을 거시 간선으로 묶고 비용을 보존해 복원한다. 압축 방식과 보존한 경로 범위를 설명하며, 임의의 압축 구현을 JPS·Subgoal Graphs 검증 완료로 취급하지 않는다. |
| S6 | 필요한 장애물만 단계적으로 반영하는 탐색 | 일부 장애물로 정확히 탐색한 뒤 전체 지도에서 충돌한 장애물을 추가해 반복한다. 모든 반복 비용을 합산하고, 각 완화 문제의 정확한 해 및 최종 전체 충돌 검증을 확인한다. |

팀 분담표의 기실험 상태는 사용자가 전달한 상태다. 현재 main·gm·sm에 있는 자료만으로 S1~S6 각각의 결과 검증 완료를 표시할 수는 없다. gm의 `proposed.py`는 안내를 검증한 뒤 원 LLM-A* 또는 g+2h로 전환하는 V-Gate이며, 경유점을 정제하거나 오류 피드백을 보내는 S1·S2 구현으로 간주하지 않는다. gm 조사서의 S4·S5 관련 항목은 미실험 제안으로 기재되어 있다.

## 공통 결과 기록 기준

각 방법의 기존 자료를 먼저 확인하고, 빠진 비교·검증만 보완한다.

- 방법 ID, 최종 담당자, 최초 구현·실험자, 코드 경로와 커밋을 기록한다.
- 실행 명령, 환경, 입력 지도·시작/목표·seed, 모델 ID·프롬프트·생성 설정과 응답 캐시를 기록한다.
- 동일한 이동 비용, 8방향 이동, 선분 장애물 충돌·벽 접촉·경계 규칙을 적용한다. 학습·보정·설정 선택 지도와 평가 지도는 구분한다.
- A*, 원 LLM-A*, 고정 g+2h 등 사용한 비교군을 밝힌다. 고정 g+2h와 Dynamic Weighted A*는 구분한다.
- 경로 유효성·길이, operation·storage, 집계 방식·분모와 실패·악화 사례를 남긴다. 원본 operation은 중복을 포함한 heap pop 횟수다.
- 전처리, 모든 탐색 큐와 반복, 경로 수리·복원, 충돌 검사, 실제 실행시간, API 호출·토큰 비용을 포함해 비용 범위를 명시한다.
- 같은 응답으로 탐색 방법만 비교할 수 있으면 캐시를 공유한다. 프롬프트·호출 방식을 바꾼 비교는 설정 차이와 추가 비용을 밝힌다.

## 인계할 기존 실험

| 새 최종 담당자 | 인계 항목 | 승민이 전달할 내용 |
| --- | --- | --- |
| 규민 | K1 통로·우회 종류 선택, K2 Conformal Prediction | 기존 코드 커밋·설정·결과·한계. |
| 준연 | J1 CHOMP 계열 경로 수리, J2 Fast Marching | 기존 코드 커밋·설정·결과·한계. |

이 네 방법의 개별 기실험 자료도 현재 모음에서는 확인되지 않았다. [gm 조사서](references/gm/최신/V-Gate_이후_개선_방법_조사.md)의 관련 설명은 참고 자료로 포함했다. 자료 인계 후 검토·보완은 새 담당자가 맡고, 최초 구현·실험자는 승민으로 유지한다.
