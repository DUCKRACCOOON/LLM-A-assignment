## 개발과 검증에 따른 판단

선택한 R1 변형은 sparse, R2 초기화는 program, R3 후보 수는 2다. 실용 목표의 검증 통과 여부는 R1=False, R2=False, 결합=False, R3 LLM 확장수 기준=False다.

목표를 통과하지 못한 정확 후보도 최종 지도에서 진단 목적으로 측정했으며, 그 결과를 사전 통과한 확증 후보인 것처럼 승격하지 않는다. R3가 규칙 대비 확장 수 개선 기준을 못 넘으면 최종 400문제의 추가 LLM 생성을 중단하고 규칙·무작위 안내만 평가한다. 이 경우 LLM의 최종 미관측 지도 성능을 주장하지 않는다.

R3 개발의 LLM/RULE 비율은 확장 수 1.062, 추론 포함 시간 20.460다. 검증의 비율은 확장 수 1.054, 시간 18.455다. 후보 생성 비용도 모두 포함했다. 출입구 순서의 유한한 후보를 사용한 것으로, 엄밀한 homotopy 분류의 완전성을 주장하지 않는다.

## 검증과 반복 측정

독립 선분 교차 그래프와 Dijkstra로 정답을 만들고 각 지도의 간선 표본을 원래 스칼라 충돌 판정과 대조했다. 최종 저장 경로를 원래 충돌 규칙·정수 단위 이동·길이 상한으로 다시 검증했다. 오류 0건, 실행 실패 0건이다. 작은 무작위 문제 2,000개와 도달 불가능 사례는 server_preflight.json에 별도 기록했다.

시간은 동일 CPU 설정에서 방법 순서를 섞은 5회 중앙값이다. 모델 응답은 문제당 한 번 생성해 w 조건에 공유하고 실제 생성 시간을 온라인 비용에 포함했다. RSS는 5ms 간격 표본 최대값이므로 순간적인 할당 최대값과 다를 수 있다. 실제 모델 생성 174회, 총 생성 토큰 9,147개다.

## 추가 평가와 자료

scaling 폴더는 동일 원형 지도의 1·2·4·8배 확대 결과다. reuse 폴더는 목표 변경·고정 및 1·5·10개 질의를 구분한 실제 누적 비용이다. 같은 목표 조건에는 FMM과 역방향 Dijkstra도 포함했다. 반복 질의 결과의 지도 수와 확대된 조건 수를 독립 표본으로 더하지 않는다.

summary.json에는 지도 bootstrap 10,000회의 대응 신뢰구간이 있으며, 주요 네 비교의 시간 구간은 다중성을 반영한 98.75% 구간으로 구분한다. 실패가 있으면 성공 문제에 조건부인 요약임을 표시하고 전체 우위로 결론 내리지 않는다.

프로토콜과 세부 설정은 protocol_frozen.json, 원자료는 per_case.jsonl·timings.jsonl, 예산은 actual_budget.json, 검증은 verification.json에 있다. 프로그램·프롬프트·원응답과 모델 revision도 보존했다.
