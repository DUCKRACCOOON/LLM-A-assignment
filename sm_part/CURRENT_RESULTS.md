# 현재 공식 결과와 이전 결과 폐기

**2026-10-28부터 SM 브랜치의 공식 S1~S6 결과는
[GM 기준·Python 3.11 재실험](gm_retest_20261028/results/s1_s6_gm_20261028/report.md)이다.**

이전 SM 실험 결과·추천·순위는 현재 평가 근거로 폐기한다. 과거 파일은
감사와 재현을 위한 이력이며 현재 결과로 인용하거나 새 결과와 합쳐 순위를 매기지 않는다.
환경·평가 문제·LLM·계측 정의가 다른 과거 실험을 동일 조건의 결과로 취급했던 해석을 바로잡는다.
이 조치는 모든 과거 실행의 수치가 조작됐다는 주장이 아니다.

이번에 대체된 방법은 S1~S6이다. 이전 SM 묶음에 포함된 K1·K2·J1·J2는
이 SM Python 3.11 실행의 대체 결과가 없으므로 그 과거 수치를 현재 순위에 쓰지 않는다.
다른 담당 브랜치의 원자료는 이번 푸시에서 수정하지 않는다.

푸시 뒤 JY 최신 커밋 `cd7d490`에서 네 방법을 포함한 COMMON18 공통 실험을 확인했다.
[18개 비교 재검토](18_methods_review_20261028/report.md)는 그 독립적인 새 실행만으로
비교한다. Python 3.12.14, S4의 과거 seed11, S6의 과거 고정 점수 등 설정 차이를
명시하며, 이 SM 공식 결과를 COMMON18 수치로 교체하지 않는다.
