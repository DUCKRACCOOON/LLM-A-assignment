# K6 실행 전 고정 규약

2026-10-25 · gm · K3–K5 결과를 확인한 뒤 설계. K6 성능 측정 전에 설정을 고정하며 사후 좋은 조건으로 주 방법을 바꾸지 않는다.

## 기존 아이디어와 이번 결정

기존 문서의 K6는 `f=g+h+α·d(n,t)`이며 α 조절법은 미정이었다. α=0이면 g+h가 되므로 g+2h와 비교할 때 안내 제거와 탐욕성 감소가 섞인다. 이번에는 그 초안식도 평가하고, **안내를 끄면 g+2h0로 돌아가는 제한된 혼합식**을 주 방법으로 둔다. h0는 K3 octile＋벽 하한이다.

주 점수는 `f=g+H`, `H=w·h0 + α·(w−1)·(min(d(n,t),h0)−h0)`이다. 주 w=2, α∈[0,1]. 따라서 h0≤H≤w·h0, 목표에서 H=0이다. d는 현재 경유점까지 직선거리다. 목표로 가는 마지막 단계 및 사용할 중간 경유점이 없을 때 α=0이다. α=0이면 g+w·h0와 정확히 같다. LLM이 멀리 있는 경유점으로 불필요하게 점수를 키우는 부분은 잘라낸다. 가까운 경유점의 후보 점수를 낮춰 안내한다. 원 논문이나 기존 초안의 수식과 달라진 부분을 명시한다.

초안식 대조군은 `H=h0+α·d(n,t)`를 그대로 쓴다. 중간 경유점이 끝나면 동일하게 α=0이므로 마지막 단계는 g+h0다. 목표의 H는 명시적으로 0이다. 이 대조군에는 일반적인 2배 비용 보장을 주장하지 않는다. 이 실험의 fixed/literal 조건은 같은 새 엔진 안의 대조군이며 원본 LLM-A*와 동일하다고 부르지 않는다.

## 경유점과 조절 규칙

- 기존 실제 GPT 응답을 strict 2차원 유한 좌표로 파싱한다. 격자 정수 좌표(정수인 float 포함), 경계 내부, 벽 위가 아닌 점만 유지한다. 소수 좌표를 임의로 반올림하지 않는다. 시작/목표 좌표와 연속 중복은 중간 목록에서 제외하고 목표를 마지막에 붙인다. 지점 간 선분 전체가 유효한지를 검사해 목록 전체를 거부하지 않는다. 경로 수리나 추가 GPT 호출은 없다.
- 현재 target을 실제로 선택·확장한 경우 다음 target으로 옮긴다. 이후 target이 이미 확장된 점이면 건너뛴다. 경유점의 순서는 안내 순서이며 반환 경로의 강제 방문 순서가 아니다. 원본의 이웃 관찰만으로 target을 바꾸는 동작과 다르며 모든 K6 대조군에 공통 적용한다.
- 주 방식: 각 새 target에서 α=0.5로 시작. **8회 유효 이웃 확장**을 한 구간으로 삼는다. 그 구간에서 관측한 target까지의 최저 거리가 직전까지의 최저 기록보다 1격자 단위 이상 낮아지면 α←min(1,α+0.25), 아니면 α←α/2. α≤1/16이면 0으로 끄고 그 target에서 재활성화하지 않는다. target 변경 시 다시 초기화한다. 마지막 목표 단계는 α=0으로 유지한다.
- 관측점은 탐색이 실제 선택한 노드이며 로봇이 이동한 궤적이나 최적 경로가 아니다. 작은 개선도 최저 거리 기록에는 반영한다. 1 미만의 개선을 여러 구간에 쌓아 임계값을 넘기는 방식은 아니다. 정체 중 다른 경유점을 강제로 넘기지 않는다.
- 더 낮은 g가 발견되면 CLOSED도 재개방한다. α/target 변경 시 현재 OPEN 전체의 키를 새로 계산하고 heapify한다. stale 키를 남긴 채 새 점수의 최솟값이라고 가정하지 않는다. 재계산 스캔·버려진 heap 항목·새로 구성한 항목·시간을 따로 기록한다.

## 데이터·반복·검증

- K4/K5와 같은 공개 1,000문제 및 기존 별도 30문제(seed=20261013). K3의 추가 120문제와 다르다. 이미 본 평가 집합이며 미지 holdout으로 주장하지 않는다.
- GPT-4o mini 2024-07-18 standard/Few-shot 응답 1,030개 고정 재생. 원 요청·해시 확인. 신규 API 0회.
- K6는 결정적이며 3회 시간 반복. K5 세 조건은 **이전 K5와 동일한 5시드**와 각 3회 반복을 유지한다. 그 밖의 비교군은 3회. 문제당 93회 실행, 공개 93,000회·별도 2,790회. 파일럿 30문제는 공개 데이터의 부분집합이며 추가 독립 표본이 아니다.
- 실행 순서 및 지도 bootstrap seed=20261028. 5시드 조건은 문제별 시드 산술평균, 시간은 시드별 반복 중앙값, 최종 상대 비율은 문제 간 기하평균. 지도 bootstrap 2,000회. 고정 시드 평균에 조건부인 구간이며 모든 시드 불확실성이나 다중 비교 보정을 포함하지 않는다.
- 독립 정수 기하·Dijkstra로 모든 경로 및 제한된 점수 조건의 w 상한을 검사한다. heap 없는 전체 OPEN 스캔 참조와 선택/α/target 순서를 비교한다. 하한은 동일 수식을 재사용하지만 참조의 그래프/큐/제어 갱신은 독립이다. 제어 단위 검사, 도달 불가·끝점 접촉·재개방·잘못된 경유점·목표 없음 등을 포함한다.
- 과거 K5 기록과 모든 기존 비교군의 경로·pop·storage·길이를 비교한다. no-guide는 기존 clean weighted A*와도 비교한다. oracle는 실제 탐색에 전달하지 않는다.

## 비용 제한의 근거와 측정

제한된 혼합식에는 admissible h0, h0≤H≤w·h0, 목표 H=0, 개선 g 재개방, 변경된 점수의 OPEN 정확한 재정렬이 필요하다. 최적 경로에서 g가 최적인 frontier 노드 n이 남아 있고, 그 키는 g*(n)+w·h0(n)≤w·C*다. 최소 키인 목표를 선택하면 C≤w·C*다. 이 논리는 우리 혼합식에 적용한 설명이며 초안식의 임의 waypoint 거리에는 적용하지 않는다. 수치 비교 오차 1e-8로 실제 비용을 검증한다.

Weighted A*와 재개방은 [Hansen & Zhou, Anytime Heuristic Search, §2.1–2.2](https://arxiv.org/pdf/1110.2737)를 참고한다. 이번 구현은 Anytime A* 전체 재현이 아니다. 동적 순위의 OPEN 유지 비용 문제는 [Dynamic Potential Search](https://ojs.aaai.org/index.php/SOCS/article/view/18392)에서도 다루지만 해당 점수식은 사용하지 않는다. α 제어·안내 혼합은 과제용 설계이며 문헌의 검증된 성능 수치처럼 소개하지 않는다.

operation은 모든 실제 heap pop이다. heapify는 pop이 아니므로 **rekey_scans, rekey_entries, rekey_discarded, heap_rebuilds**를 별도 보고한다. operation 감소만으로 총 연산 감소라고 주장하지 않는다. 실제 이웃 확장은 목표를 제외한다. storage는 inf 항목 포함 g 사전 크기이지 전체 RAM이 아니다.

매 시행 파싱·필터·하한 생성·거리/제어·재정렬·탐색·반환 경로 검증을 계획기 시간에 포함한다. 파일 IO·oracle·기록·전역 geometry 캐시 비우기는 제외한다. 과거 API 지연을 별도 보존하며 오프라인 계획기 시간을 온라인 전체 시간으로 부르지 않는다. 원시 반복·시드·경로·해시·과정·실패 사례·AI 지원 기록을 gm K6 폴더에 저장한다.
