# K6 자동 비교표

기준 g+2h=100. 문제별 비율의 기하평균. K5는 문제별 5시드 평균, 시간은 시드별 3회 중앙값을 먼저 사용했다.
전체 pop은 heapify/전체 재계산 횟수를 포함하지 않는다. 이 비용은 별도 표와 계획기 시간에 포함한다. LLM 생성 지연은 제외했다.
