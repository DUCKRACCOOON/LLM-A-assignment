# J3 공개 전체 데이터셋 1회 평가

2026-11-11, jy. J1/J2에 이어 J3(유효한 초기 경로 상한 가지치기)만 새로 평가한다.

- 공개100지도×10쌍=1,000문제, 이전 두 평가와 같은 입력·이동·비용·닫힌 선분 충돌 규칙이다.
- results/main의 GPT-4o mini standard 응답1,000건을 요청 본문·입력·모델·SHA와 확인해 고정한다.
  다른 수집의 응답과 섞지 않고 잘린 응답도 보존한다. 새 API 호출0회, 실행 중 네트워크/API 연결을 차단한다.
- 기존 experiments/JY/search.py의 구현을 그대로 사용한다. 유효한 seed 경로의 비용U와 octile 하한에 대해
  g+h≥U인 후보를 제외한다. 나중에 더 낮은g로 도달하면 다시 후보가 될 수 있다. 단순 가지치기이며 ARA* 전체 구현이 아니다.
- 주 J3는 원 LLM-A*의 유효 격자 경로를 seed로 사용한다. 실패 시 g+2h fallback을 하며 해당 계산도 포함한다.
  seed를 얻은 뒤 w=1 정확 A* refinement를 수행한다. oracle 경로/비용은 온라인 탐색에 전달하지 않는다.
- J3_no_prune은 같은 LLM seed+같은 정확 refinement에서 상한 가지치기만 제거한다.
  J3_noLLM은g+2h seed+가지치기, J3_noLLM_no_prune은같은g+2h seed+무가지치기다.
  seed를 구한 뒤 무가지치기하는 대조는 구성요소를 분리하기 위한2단계 대조이며 추천 단일 알고리즘이 아니다.
- 추가 대조 Astar/LLMA/G2H/Octile/WallAstar를 포함해 총9조건이다. LLMA/G2H 외7조건은 최단성 보장을 목표로 한다.
  Octile과 WallAstar는J3 refinement와 같은 clean A* 엔진을 쓰는 단일 탐색 대조다.
- 문제·조건별 정확히1회, 총9,000회. CPU/native1스레드, seed20261111로 방법 순서만 섞는다.
  모든 대조를 이번 실행에서 다시 측정한다. J1/J2 및 과거 JY의 시간과 합산하지 않는다.
- 파싱·지도 생성·초기 seed 탐색·유효성 검사·refinement·복원·필수 검증을 로컬 시간에 모두 포함한다.
  seed/refinement가 같은 질의 안에서 이웃 캐시를 재사용하는 기존 설계를 유지하되 질의/방법 사이에는 공유하지 않는다.
  파일 읽기·독립 기하 Oracle/Dijkstra·집계는 타이머 밖이다.
- LLMA/J3/J3_no_prune은논리1회, 다른 조건은0회다. 과거 API 지연+현재 로컬의 총시간은 재구성 추정으로 현재 서비스 실측이 아니다.

  seed 길이/operation이 대응 LLMA/G2H와 같은지, 두 단계operation 합계도 저장 원자료에서 검산한다.
