## 각 실행 안에서의 판단

- J1: 원 LLMA보다 경로 품질은 개선했으나 수리·준비 비용이 증가했고 무안내 FOCAL 대조도 더 유리했다.
- J2: 원 LLMA보다 경로 품질은 개선했으나3응답 비용과 준비 비용이 컸다. 균일 FMM 대조보다도 불리했다.
- J3: 같은2단계에서 가지치기 성분은 유리했다. LLMA에 평균 약1.69ms를 더해 최단성을 확보했지만 단일 정확 탐색보다 빠르지는 않았다.
- J4: 준비 후 검색은 줄었지만 단일 질의 전처리 비용이 컸다. 지도당10질의의 전처리1회 합산 추정도 ALT4/Octile 비용합1.0364였다.
- J5: NBS octile은 단일 octile A*보다 평균37.9% 느렸다. 양방향 Dijkstra 대비 이득을 강한 A*에 대한 우위로 확대하지 않는다.

## 결과를 합쳐 읽을 때

여섯 연구는 같은 공개 입력·호스트·런타임·저장 응답을 사용했지만 서로 다른 실행 블록이다.
각 보고서의 비교군은 해당 블록에서 함께 측정했다. 블록 사이 절대 시간만 정렬해 하나의 엄밀한 속도 순위를 만들지 않는다.
특히 J6는두 방식 모두 유효 선택열 기록을 포함하며, 다른 연구에는 그 계측이 없다.

각 연구는 시간1회이므로 반복 안정성은 평가하지 않았다. 지도 bootstrap 구간은 문제 구성의 탐색적 불확실성이다.
공개 자료는 연구에 이미 노출됐고 test200은 전체의 부분집합이다. 별도 독립 문제 수로 더하지 않는다.
API 포함 시간은 과거 지연+현재 로컬의 재구성 추정이며 현재 온라인 반복 실측이 아니다.
J2는standard/CoT/RePE3응답, 다른 LLM 사용 조건은standard1응답을 사용하며, J4/J5 자체는온라인LLM0회다.
