# 18개 방법 vs 원 LLM-A* — 단일 측정 블록 비교 (정규화 전)

2026-11-12, gm. 공개 1,000문제(100지도×10쌍), SM 통합 규칙(지도 단위 5-fold OOF, 문제당 51조건×5회, 반복마다 순서 섞음, 5회 중앙값, 네트워크 차단, 1스레드, 해시 고정).
S·J·K 18개 방법과 A*·LLM-A*를 **한 PC, 한 실행 블록**에서 측정했다(Python 3.11.9, Intel64 Family 6 Model 151 Stepping 5, GenuineIntel). 5개 fold는 병렬 프로세스로 실행했다. 같은 문제 안에서 모든 조건이 섞여 실행되므로 비율 비교는 공정하지만 절대 ms는 단독 실행보다 클 수 있다.

비율은 문제별 (방법 ÷ 원 LLM-A*)의 기하평균이다. 100% 미만이면 원 LLM-A*보다 작다(시간·연산·메모리는 좋음). [ ]는 fold 내 지도 단위 bootstrap 2,000회 95% 구간, ×는 문제별 비율의 기하 표준편차, ±는 문제별 원값의 표준편차.
