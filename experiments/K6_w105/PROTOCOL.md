# K6 5% 제한 대조 실험: 실행 전 고정 규약

2026-10-25 · gm · 기존 K3–K6 결과를 본 뒤 계획한 후속 실험이다. 아래 신규 대조 결과를 보기 전에 조건을 고정한다. 처음부터 독립적인 확인 실험이나 미지 holdout이라고 주장하지 않는다.

## 질문과 고정 조건

K6의 w=1.05 조건이 K4/K5보다 효율적이었던 이유 중 LLM 안내 및 적응 α의 추가 기여를 확인한다. 기존 K6의 graph_search, Controller, prepare_targets, K3 하한 구현을 수정 없이 가져온다. 새로운 얇은 실행 함수에서 설정만 바꾸며 기존 K6의 코드·규약·측정 파일은 보존한다.

모든 K6 조건은 같은 octile＋벽 하한 h0, 8방향 이동, 충돌 규칙, CLOSED 재개방, tie-break, 목표 종료, 파싱/필터 및 target 전환 규칙(안내를 사용하는 경우)을 사용한다.

`H=1.05·h0 + α·0.05·(min(d(node,target),h0)−h0)`, `f=g+H`.

K6 적응/고정 조건 모두 중간 경유점이 없거나 마지막 goal 단계이면 α=0이다. '고정'은 이 전환까지 없앴다는 뜻이 아니다. 고정 조건도 target 변경 시 OPEN을 재정렬한다. no-guide에는 경유점 파싱·필터·거리 계산·target 전환이 없고 동일 엔진의 기본 관측 bookkeeping은 남는다.

중요한 직접 비교는 적응/no-guide, 고정0.5/no-guide, 고정1/no-guide, 적응/고정0.5, 적응/고정1이다. K3는 w=2이며 기존 CLOSED 규칙도 다르므로 K6/K3 비교만으로 LLM 기여를 주장하지 않는다. no-guide 대비 차이도 전체 안내 기능의 효과이며 모델 좌표 내용과 점수식 변화의 순수 인과 효과를 완전히 분리하는 실험은 아니다.

## 데이터·측정

- 기존 공개 100지도×10쌍=1,000문제, seed=20261013의 기존 별도 10지도×3쌍=30문제. K3 추가 120문제와 다르다.
- GPT-4o mini 2024-07-18 standard/Few-shot의 동일 실제 응답 1,030개. 원 입력·프롬프트·응답 해시를 확인한다. 신규 API 0회.
- 전 조건 결정적이다. 같은 문제에서 7조건×5회 순서를 섞어 실행하고 시간 중앙값을 쓴다. 5회는 새 LLM 응답/독립 문제/난수 알고리즘 시드가 아니다.
- 공개 부분집합 파일럿 30문제(기존과 같은 선택), 공개 전체, 별도 30문제 순서로 실행한다. 공개 35,000회, 별도 1,050회, 파일럿 1,050회로 총 37,100회다. 파일럿은 독립 표본 수에 포함하지 않는다.
- 실행 순서 및 bootstrap seed=20261029, 지도 단위 2,000회 bootstrap. 상대 비율은 문제별 비율의 기하평균. 경로 길이 변화의 동일 판정 오차는 1e-8. 절대 산술평균·최단경로 건수·최악 초과율도 보고한다. 다중 비교 보정은 하지 않는다.
- 초기 동일 환경 캐시를 매 실행 전후에 비우되 그 비우기 자체는 시간 밖이다. 파싱·필터·하한 준비·탐색·제어·OPEN 재정렬·경로 검증은 시간 안, 파일 IO·독립 Dijkstra·기록·과거 동등성 확인은 밖이다. 다른 벤치마크를 동시에 실행하지 않는다.
- operation은 전체 heap pop. successor_expansions, rekey_scans, heap_rebuilds, 거리 계산, 실제 시간을 별도로 보고한다. pop 감소를 총 연산 감소라고 표현하지 않는다. storage는 g 사전 크기이며 전체 메모리가 아니다.

## 검증·분석

- 독립 정수 기하 그래프와 Dijkstra로 모든 경로·최단거리를 확인한다. K6 네 조건은 실제 비용≤1.05C*를 검사한다.
- heap 없는 전체 OPEN 스캔 참조와 경로·선택·target·α를 비교한다. 기존 Controller 테스트를 가져온 전제 위에서 새 고정 α/안내 없음/끝점/도달 불가/재개방을 확인한다.
- no-guide는 별도 구현인 K4의 clean weighted 검색을 weight=1.05로 호출한 결과와 모든 문제에서 비교한다. 이 참조는 계획기 성능 집계에 넣지 않는다.
- 적응 조건은 기존 K6 5%의 모든 비시간 지표, 기존 기준 3조건은 기존 K6의 경로·pop·저장량·길이·실제 확장과 일치해야 한다. 원시 5회 경로·제어·큐 지표도 일치해야 한다.
- 전체 집계 외에 유효 중간 경유점이 남은 부분집합을 별도 진단한다. 전체 결과를 대체하지 않는다. no-guide 대비 pop·길이의 개선/동일/악화 및 둘 다 악화하지 않는 사례를 남긴다.
- 고정 α에서는 더 보수적인 점수 및 heap 정리 방식이 달라질 수 있다. 좋은 길이를 모두 LLM의 의미 이해에 귀속하지 않는다. 5% 제한 달성 자체는 하한·재개방·정렬 규칙의 성과다.
- 사후 그림 사례는 적응/no-guide pop 최선·최악, 적응/고정0.5 pop 최악을 유효 안내 문제 중 고른다. 극단 사례이며 평균적 사례라고 부르지 않는다.
- 실패·악화를 숨기지 않는다. 적응 결과가 불리해도 주 조건을 좋은 고정값으로 교체하지 않는다. 설정 변경 없이 완료한 자료에서 최종 방법 추천을 갱신한다.

이번 과제용 실험의 구현·검증·집계·문서 초안은 Codex 지원으로 작성한다. 사용자/팀의 이해·문장 검토와 최종 제출은 별도다. 기존 재현 및 K6 기록의 사실을 소급해서 바꾸지 않는다.
