## 현재 비교 메모

K3는 공개 지도에서 g+2h 대비 pop 48.74% 감소·길이 0.79% 감소·시간 22.19% 감소를 보였다. 새 지도에서는 pop 17.70% 감소·길이 0.07% 증가·시간 14.37% 증가였다. 문제별 비율의 기하평균이며 전 문제에서의 개선을 뜻하지 않는다. 사전 주 방법은 octile＋벽 하한이고, 비교 조건인 직선거리＋벽 하한은 더 유리한 집계 결과를 보였다. [두 조건을 구분한 수치표](K3/results/run_20261025/analysis/TABLES.md).

K3에는 LLM 호출이 없었다. 기하 하한 자체의 기여를 확인한 실험이며 최종 LLM 결합 개선안의 효과를 대신하지 않는다.

K4는 기존 실제 GPT 응답을 고정 재생했다. 공개 데이터에서 K3 주 방법 대비 길이는 0.35% 짧았지만 전체 heap pop 4.20배, 계획기 시간 3.33배였다. 개별 경로의 최단거리 대비 5% 제한은 전 문제에서 지켰다. 같은 FOCAL에서 LLM을 제거한 조건이 더 좋은 결과여서 LLM의 추가 성능 이득은 확인하지 못했다. **속도·연산량 중심 후보는 현재 K3를 유지한다.**

K4의 별도 30문제는 기존 응답이 있는 seed=20261013 자료다. K3의 seed=20261025 새 지도 120문제와 다르므로 두 추가 평가의 수치를 직접 대조하지 않는다. K4 실험 안에서는 g+2h·K3·K4를 동일한 30문제로 다시 비교했다.

공개 1,000문제 공통 비교(최신 K4 실행, g+2h=100, 문제별 비율 기하평균):

| 방법 | 전체 heap pop | 길이 | 계획기 시간 | 최단+5% 초과 사례 |
| --- | ---: | ---: | ---: | ---: |
| g+2h | 100.00% | 100.00% | 100.00% | 153/1,000 |
| K3 octile＋벽 | 51.26% | 99.21% | 77.96% | 96/1,000 |
| K3 직선거리＋벽 | 48.19% | 98.83% | 71.99% | 44/1,000 |
| K4 LLM＋5% 제한 | 215.34% | 98.87% | 259.73% | 0/1,000 |
| FOCAL 5%, LLM 제거 대조군 | 202.81% | 98.27% | 194.10% | 0/1,000 |

시간에는 LLM 생성 시간을 포함하지 않는다. K4의 전체 pop은 세 heap의 관리 pop을 합한 값이며 실제 탐색 횟수도 [K4 보고서](K4/REPORT.md)에 따로 남겼다. 아직 다른 담당 방법을 모두 평가한 상태가 아니므로 최종 제출 방법은 선정하지 않았다.

## K5 추가 비교 (2026-10-25)

K5는 13조건, 확률 조건별 5시드, 시간 측정 3회로 평가했다. 파일럿 포함 92,220회 유효 경로 검증과 79,500회 비용 상한 검사를 통과했다. 공개 데이터에서 주 K5는 g+2h 대비 전체 pop 105.59%, 길이 100.48%, 계획기 시간 300.23%였다. K3 주 방법 대비 pop 2.06배, 길이 1.28% 증가, 시간 3.88배로 **현재 후보 우선순위는 K3를 유지한다.**

DTS는 고정 순환보다 이웃 확장을 8.58% 줄였지만 시간은 20.47% 늘었다. LLM 큐를 제거한 조건이 주 K5보다 유리했다. K4와 같은 5% 상한의 K5도 평가했으며 공개 pop은 K4보다 18.27% 적지만 시간은 65.58% 더 들었다. 주 K5의 2배 상한과 K4의 5% 상한을 혼동하지 않는다. [K5 전체 과정·원시 결과·악화 사례](K5/REPORT.md).

위의 이전 K4 실행 표는 당시 기록으로 보존한다. K5의 동일 시점 재측정 시간은 K3 주 방법 77.37%, K3 직선거리 변형 71.98%, K4 주 방법 256.22%(g+2h=100)다. 결정적인 경로·pop·storage는 과거 기록과 모두 일치했다. 시간에는 LLM 생성 지연이 포함되지 않는다.

## K6 추가 비교 (2026-10-25)

K6는 탐색 진전에 따라 경유점 가중치 α를 조절하는 단일 큐 방식이다. 공개 1,000문제·기존 별도 30문제에서 19조건을 비교하고, 기존 K5의 5시드도 그대로 재실행했다. 파일럿 포함 98,580회 경로 검증과 79,500회 비용 상한 검사를 통과했다. [K6 과정·대조 실험·개선/악화 사례](K6/REPORT.md).

최신 K6 실행에서 공개 g+2h=100(문제별 비율 기하평균):

| 방법 | heap pop | 길이 | 계획기 시간 |
| --- | ---: | ---: | ---: |
| g+2h | 100.00% | 100.00% | 100.00% |
| K3 octile＋벽 | 51.26% | 99.21% | 77.37% |
| K3 직선거리＋벽 변형 | 48.19% | 98.83% | 71.62% |
| K4 LLM＋5% 제한 | 215.34% | 98.87% | 253.72% |
| K5 DTS＋2배 제한 | 105.59% | 100.48% | 296.80% |
| K6 주 설정, 2배 제한 | 62.69% | 99.21% | 127.65% |
| K6 비교 설정, 5% 제한 | 109.84% | 98.05% | 195.06% |

주 K6는 K3보다 pop 22.28%·시간 64.98% 증가했고 길이는 사실상 같았다. 같은 엔진에서 안내를 끈 대조군보다도 pop 16.08%·시간 35.46% 증가하여 **속도 중심 후보는 K3를 유지한다.** K6 pop에는 OPEN 전체 재계산을 세지 않는다. 공개 문제당 평균 172.597항목의 재계산과 그 시간을 별도로 기록했다.

같은 5% 제한의 K6는 K4 LLM 대비 공개 pop 48.99%·시간 23.12% 감소하고 길이 0.82% 감소였다. 품질 제한 후보로 보관하되 같은 K6 엔진의 1.05 no-guide/고정 α 대조가 없으므로 LLM·α 제어의 독립 효과는 미확인이다. K4 LLM 제거 조건과 비교하면 시간 우위가 없었다. 별도 지도 결과와 최악 경로도 보고서에 보존했다. 모든 시간은 API 생성 지연을 제외한 계획기 시간이며, 기존 결과의 경로·pop·storage는 과거 기록과 일치했다.

## K6 5% 제한의 추가 대조 (2026-10-25)

위 K6 기록에서 미확인으로 남긴 동일 엔진의 1.05 no-guide/고정 α 비교를 완료했다. 기존 K6 코드를 수정 없이 가져왔고 K3 직선거리＋벽 하한도 같이 재측정했다. 7조건×시간 5회, 파일럿 포함 37,100회 경로 검증·21,200회 비용 상한 검사를 통과했다. [과정·원시 결과·사례](K6_w105/REPORT.md).

공개 1,000문제에서 **LLM 제거 조건=100**인 직접 비교:

| K6 5% 조건 | heap pop | 실제 이웃 확장 | 길이 | 계획기 시간 |
| --- | ---: | ---: | ---: | ---: |
| LLM 제거 | 100.00% | 100.00% | 100.0000% | 100.00% |
| 적응 α | 94.95% | 102.97% | 100.0029% | 120.37% |
| 고정 α=0.5 | 99.00% | 103.42% | 99.9819% | 116.88% |
| 고정 α=1 | 115.05% | 119.76% | 99.9799% | 130.71% |

적응형의 pop 감소는 평균 이웃 확장 감소가 아닌 stale pop 감소에서 나왔고 OPEN 재계산 비용이 추가됐다. 고정 α는 작은 길이 이득이 있었지만 비용이 늘었다. 별도 30문제에서는 네 조건의 길이가 모두 같았다. **효율 1순위는 K3 직선거리＋벽, 개별 5% 제한용 비용 기준은 LLM 없는 g+1.05h0로 갱신한다.** LLM 또는 적응 제어의 실용적인 순이득은 확인하지 못했다.

이번 실행의 g+2h=100 수치는 K3 직선거리 pop 48.19%·길이 98.83%·시간 71.50%, K6 적응 109.84%·98.05%·192.76%, no-guide 115.68%·98.05%·160.14%다. K3는 w=2이므로 이 비교를 LLM의 인과 효과로 해석하지 않는다. API 생성 시간은 제외했고 신규 호출은 0회다. 첫 실행의 시간 필드 동등성 검사 오류 및 실패 기록도 보존했다.

## 방법별로 남기는 항목

1. 원리·구현 범위·원 논문/참고 연구와의 관계.
2. 실행 전에 고정한 비교군·데이터·설정·가설.
3. 경로·알고리즘 검증, 실패 처리와 기존 비교군의 동등성.
4. 입력과 seed, 반복별 원시 지표, 전처리·API·시간의 포함 범위.
5. 전체 결과와 구성요소 제거 비교, 개선·동일·악화 건수.
6. 좋아진 사례와 나빠진 사례, 제한점, 다음 방법 선정에 쓸 판단.
7. 코드·데이터 해시·환경·실행 명령, 실제 기여와 AI 지원 기록.
