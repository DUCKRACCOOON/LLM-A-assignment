## 현재 비교 메모

K3는 공개 지도에서 g+2h 대비 pop 48.74% 감소·길이 0.79% 감소·시간 22.19% 감소를 보였다. 새 지도에서는 pop 17.70% 감소·길이 0.07% 증가·시간 14.37% 증가였다. 문제별 비율의 기하평균이며 전 문제에서의 개선을 뜻하지 않는다. 사전 주 방법은 octile＋벽 하한이고, 비교 조건인 직선거리＋벽 하한은 더 유리한 집계 결과를 보였다. [두 조건을 구분한 수치표](K3/results/run_20261025/analysis/TABLES.md).

K3에는 LLM 호출이 없었다. 기하 하한 자체의 기여를 확인한 실험이며 최종 LLM 결합 개선안의 효과를 대신하지 않는다. 아직 다른 담당 방법을 모두 평가한 상태가 아니므로 최종 방법은 선정하지 않았다.
