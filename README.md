100지도 × 10문제 × 22조건 × 5회 = **110,000회** 측정. 무효 경로와 선언 상한 위반은 **0건**입니다.
S4 모델 15개를 fold별로 재학습했고 새 GPT-4o mini 응답 2,932건과 별도 RSS 측정 1,320회를 보존했습니다.
모든 방법을 현재 AMD PC의 Python 3.11.18에서 함께 측정하고 원 LLM-A*를 주 비교군으로 사용했습니다.

S1의 계획기 시간은 원 LLM-A* 대비 25.44% 감소했습니다. S6는 모든 경로가 최단이며 8.72% 감소했지만 규칙 기반 벽 선택보다 0.94% 느려 LLM 계수의 추가 이득은 확인하지 못했습니다.
API 포함 시간은 공유 수집 지연과 오프라인 계획기 시간을 합한 재구성 추정입니다. 공개 자료의 과거 노출은 교차검증으로 없어지지 않습니다.
