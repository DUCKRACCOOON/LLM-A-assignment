# 한국어 ACL 재현 보고서

본문과 그림 설명을 한국어로 작성했다. 모델 ID, 알고리즘과 프롬프트 이름,
코드 명령, 원문 참고문헌 및 ACL 기본 표기는 영어로 유지했다.
현재 문서는 `gm` 개인 실험 초안이며 팀명·저자와 학생의 직접 검토가 필요하다.

## 생성과 컴파일

저장소 루트에서 실행한다. 실제 모델을 새로 호출하지 않는다.

```bash
python -m reproduction.performance_audit
python -m reproduction.report
python -m reproduction.report_text
```

그 다음 `report` 폴더에서 컴파일한다.

```bash
tectonic --outdir ../output/pdf LLM_Astar_Reproduction_Report.tex
```

XeLaTeX 계열의 컴파일러, `kotex`, Windows 기본 글꼴 Times New Roman,
Malgun Gothic, Consolas를 사용한다. 다른 OS에서는 설치된 한글 글꼴로
`report_template.tex`의 글꼴 설정을 변경해야 한다. 이 설정은 실험 결과에 영향을 주지 않는다.

지속되는 본문 수정은 `report_template.tex`, 수치와 연결되는 한국어 문장은
`reproduction/report_ko.py`에서 관리한다. 결과 표는 저장된 JSON에서 생성한다.
그림도 `python -m reproduction.report`로 다시 생성한다.

ACL 공식 스타일은 https://github.com/acl-org/acl-style-files 에서 가져왔고
원 스타일 파일은 수정하지 않았다. 출처는 `TEMPLATE_SOURCE.json`에 기록했다.
`paper_table1.json`은 원 논문 수치의 전사본이며 자체 실험 결과가 아니다.

## 이번 재점검의 결론

- 실제 응답 6,000개, 조건별 1,000문제와 저장 기록의 일관성을 다시 검사했다.
  원본 코드와 실제 응답 62개 대조 및 A* 1,000개 길이의 Dijkstra 대조가 통과했다.
- 주 조건에서 V-Gate는 원 LLM-A*보다 탐색 횟수가 530문제에서 적고,
  272문제에서 같으며, 198문제에서 많다. 문제별 비율의 기하평균은 77.22%다.
- 파일럿 맵 전체를 제외한 900문제의 비율은 77.66%다. 사후 부분집합 분석이며
  독립적인 비공개 시험 결과로 해석하지 않는다.
- 원 LLM-A*보다 개선되었으나 LLM 없는 g+2h보다 좋은 방법이라고 주장하지 않는다.
  숨겨진 평가 환경과 점수 산식이 없으므로 성능 점수는 알 수 없다.
- Llama3 실험은 아직 없다. 원 모델은 Meta-Llama-3-8B-Instruct/bfloat16이며
  전용 프롬프트와 8,000토큰 상한을 쓴다. 2026-10-13 사용자 결정에 따라 다른 팀원이
  담당하며 이 작업 공간에서는 실행하지 않는다. GPT-4o mini로 대체한 실험과 분리해야 한다.
  팀원의 실제 설정·응답·결과를 받기 전에는 팀 차원의 완료나 수치를 추가하지 않는다.

기계 판독 결과: `results/verification/performance_audit.json`.

## 문장과 AI 검사 검토

한국어 본문에서는 일반적인 장점 나열을 줄이고, 실제 실행한 설정·수치·실패 원인과
확인하지 못한 범위를 구분했다. 원 논문의 저자, 제목, 연도도 제공된 PDF 첫 페이지와
대조했다. 사용하지 않은 Llama3의 결과, 실행하지 않은 확장 실험, 학생이 직접 검토했다는
주장은 넣지 않았다. AI 도움의 범위는 보고서에 남겼다.

이 검토는 AI 판별기나 표절 검사 결과가 아니다. AI 지원으로 작성한 초안을 사람만
작성한 글이라고 인증하지 않는다. 학생은 제출 전에 자기 이해에 따라 내용을 검토해야 한다.

2026-10-13 사용자가 보고서 전송과 약관·개인정보처리방침 동의를 승인한 뒤
Copyleaks 무료 AI 검사를 1회 수행했다. 결과는 **AI Content Found 100%**,
화면의 Sensitivity Level은 2/3이었다. 화면의 AI Text는 5,804 Words,
Human Text는 0 Words로 표시되었으며 이는 서비스가 표시한 단위다.
현재 초안을 AI 느낌이 없는 글이나 검사를 통과한 글이라고 설명할 수 없다.

입력은 [검사한 원문](../output/LLM_Astar_Report_KO.txt) 11,108자다.
PDF 추출 과정에서 한글 띄어쓰기가 사라지는 문제를 피하려고 LaTeX 원고에서
본문·표·그림 설명·참고문헌을 평문으로 변환했다. 그림 픽셀과 저자 자리표시는 제외했고
수식·참조 표기는 평문으로 옮겼다. 초기에 붙여넣었던 PDF 추출문은 Scan을 누르기 전에
교체했으며 실제 검사 요청은 이 평문으로 한 번만 보냈다. 키나 응답 로그는 전송하지 않았다.

[검사 화면](../output/ai_check/copyleaks_result.png)과
[검사 기록](../results/verification/ai_detection.json)에 점수, 범위와 입력 해시를 보존했다.
이 수치는 Copyleaks가 표시한 AI 판정이며 표절률이나 과제 채점 결과가 아니다.
과제 안내서는 검사기 이름, 통과 기준과 재현 부분의 면제 여부를 정하지 않았다.
다른 검사 결과나 무감점을 보장하지 않는다. 검사 점수는 실험 성능 지표에도 포함하지 않는다.

최종 검토에서는 4절의 g+2h 비교, 5절의 V-Gate 개선 근거, 7절의 한계를 읽고
본인이 설명할 수 있는 내용과 동의하는 해석으로 수정해야 한다. 사실이나 수치는 바꾸지
말고, 실제로 확인한 판단과 남은 의문을 반영한다. 검사 수치를 낮추기 위한 반복 변환은
하지 않았다. 이후 원고를 수정하면 이 기록은 수정 전 버전에 대한 결과로 남는다.
