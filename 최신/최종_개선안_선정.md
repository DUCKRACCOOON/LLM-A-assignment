# K3 최종 개선안 선정 기록

2026-10-25 · 규민 · gm

**gm의 최종 개선안은 K3 직선거리＋벽 하한으로 확정한다.** K3–K6와 K6 5% 제한 대조 실험을 검토한 뒤 사용자가 선택했다. 선택 기준은 탐색량, 경로 길이, 실제 실행 시간과 구현의 설명 가능성이다. 이 문서는 선정 내용과 후속 작업을 정리한 메모이며 제출 보고서는 별도 작업이다.

## 확정한 설정

| 항목 | 최종 선택 |
| --- | --- |
| 방법 이름 | K3 직선거리＋벽 하한 |
| 코드 식별자 | `g2h_wall_euclidean` |
| 구현 | [experiments/K3/heuristic.py](../experiments/K3/heuristic.py)의 `LowerBound`와 `run_once` |
| 기본 거리 | Euclidean, `base='euclidean'` |
| 벽 반영 | `walls=True`, 벽별 우회 거리 하한의 최댓값 |
| 탐색 우선순위 | `g + 2h_K3` |
| 이동·충돌·탐색 규칙 | 기존 8방향 격자, 이동 비용 1/√2, 벽 접촉 금지, 기존 tie-break·CLOSED 규칙 유지 |
| LLM 사용 | K3 탐색에는 없음. 원 논문 LLM-A* 재현 실험은 별도 비교 대상으로 유지 |

현재 위치 n에서 목표 G로 가는 직선이 벽 j에 막히면 벽 끝점 a, b를 이용한다.

```text
wall_j(n) = min(distance(n,a)+distance(a,G), distance(n,b)+distance(b,G))
h_K3(n)   = max(distance(n,G), 막힌 각 벽의 wall_j(n))
priority  = g(n) + 2*h_K3(n)
```

벽 하한을 합산하지 않으며 끝점 방문을 강제하지 않는다. 벽 끝점은 거리 하한 계산에만 사용하고 실제 경로의 충돌 판정은 유지한다. 정답 경로나 문제별 수동 설정을 입력하지 않는다.

기존 K3 실험의 사전 주 설정은 **octile＋벽 하한**이었다. 이번 최종 선택은 결과를 비교한 뒤 정한 **직선거리＋벽 하한**이다. 기존 `PRIMARY='g2h_wall_octile'`, 실행 전 규약과 실험 기록은 당시 설정으로 보존한다. 선택한 코드를 호출할 때는 아래 식별자를 명시한다.

```python
from experiments.K3.heuristic import run_once

result = run_once(query, 'g2h_wall_euclidean')
```

## 선택 근거

아래는 선택한 K3만의 결과다. 각 행에서 같은 실행의 기존 g+2h를 100으로 놓은 문제별 비율의 기하평균이며 낮을수록 좋다. 시간은 각 문제의 반복 중앙값을 사용한다.

| 평가 자료 | pop | 경로 길이 | 계획기 시간 | 근거 |
| --- | ---: | ---: | ---: | --- |
| 공개 1,000문제, 시간 5회 | 48.19% | 98.83% | 71.50% | [K6 후속 동일 조건 비교](../experiments/K6_w105/results/run_20261025/analysis/TABLES.md#public) |
| K3 합성 120문제, 시간 3회 | 79.94% | 99.55% | 107.36% | [K3 추가 지도 평가](../experiments/K3/results/run_20261025/analysis/TABLES.md#synthetic) |
| 기존 별도 30문제, 시간 5회 | 73.88% | 100.36% | 97.38% | [K6 후속 별도 지도 평가](../experiments/K6_w105/results/run_20261025/analysis/TABLES.md#transfer) |

공개 데이터에서는 pop 51.81%, 길이 1.17%, 시간이 28.50% 감소했다. 합성 120문제에서는 pop이 줄어도 시간이 7.36% 늘었고, 별도 30문제에서는 길이가 0.36% 늘었다. 세 자료는 동일한 평가 집합이 아니며 시간 반복·측정 시점도 다르다. 이를 합쳐 하나의 개선율로 만들지 않는다.

K4·K5·K6를 함께 재측정한 [K6 비교 기록](../experiments/K6/REPORT.md)에서도 K3 직선거리＋벽은 공개 데이터의 pop·시간에서 유리했다. 5% 품질 제한 방법들은 더 짧은 경로를 얻는 대신 비용이 늘어나는 절충이 있었다.

마지막 [K6 5% 제한 대조](../experiments/K6_w105/REPORT.md)에서 적응형 K6는 선택한 K3보다 길이가 0.789% 짧았지만 pop 2.279배·시간 2.696배였다. LLM을 제거해도 길이 이득 0.792%가 유지됐다. 같은 엔진에서 적응 안내는 no-guide보다 pop 5.05% 감소, 실제 확장 2.97% 증가, 시간 20.37% 증가였고 길이는 사실상 같았다. 고정 가중치의 작은 품질 이득도 있었으나 추가 비용을 상쇄하지 못했다. 따라서 LLM 안내나 적응 제어를 최종 K3에 덧붙이지 않는다.

## 설명할 핵심과 한계

- **기여:** 기존 LLM-A* 재현에서 LLM 없는 g+2h가 강한 기준임을 확인했고, 장애물 우회를 반영한 휴리스틱으로 그 기준을 개선했다. K3의 성과를 LLM 추론 성능의 개선이라고 설명하지 않는다.
- **경로 품질:** 최단경로 또는 최단+5%를 보장하지 않는다. 공개 문제에서 787/1,000개가 최단이었고 44개는 최단+5%를 초과했다. 최악 길이는 최단의 약 121.65%였다.
- **계산 비용:** pop은 큐에서 꺼낸 횟수다. 각 후보에서 벽을 검사하는 비용까지 포함한 전체 연산 수가 아니므로 실제 시간과 함께 설명한다.
- **적용 범위:** 축에 평행한 선분 장애물과 정수 8방향 격자에서 평가했다. 사용한 지도들을 보고 선택했으므로 이 결과를 새로운 미지 환경의 성능 보장으로 제시하지 않는다.
- **과제 설명:** 원 논문 재현과 이번 개선을 구분하고 원 A*·LLM-A*·g+2h 및 K3의 비교 근거, 출처, 악화 사례를 유지한다. [과제 지침 대응](과제_지침_대응.md)의 실제 구현·결과 일치 기준에 맞춘다.
