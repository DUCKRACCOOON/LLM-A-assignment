# 팀 개선 방법 실험 분담

확정일: 2026-10-14. 담당자: 규민, 준연, 승민.

**전체 18개 방법군을 6개씩 담당한다.** 승민은 이미 실험한 항목 중 6개를 계속 담당한다. 규민과 준연은 각각 승민의 기실험 2개를 인계받고, 신규 4개를 담당한다. 최초 실험자와 최종 담당자를 구분하여 승민의 선행 실험 기여를 그대로 기록한다.

| 최종 담당자 | 승민 기실험 항목 | 신규 항목 | 총 담당 |
| --- | ---: | ---: | ---: |
| 규민 | 2 | 4 | 6 |
| 준연 | 2 | 4 | 6 |
| 승민 | 6 | 0 | 6 |
| 합계 | 10 | 8 | 18 |

기실험 여부는 사용자가 전달한 승민의 10개 실험 목록을 기준으로 한다. 이 문서를 작성하는 시점에는 해당 개선 실험의 코드·실행 설정·결과 파일을 모두 확인한 상태가 아니다. **기실험 표시가 성능 검증 완료나 제출 준비 완료를 뜻하지는 않는다.** 기실험 4개의 최종 담당자를 변경해도 최초 실험자는 승민으로 유지한다.

이 문서 작성 중 새 실험이나 API 호출은 진행하지 않았다. 신규 항목은 새 실험 결과가 확인되기 전까지 미착수로 기록한다.

## 규민 담당 6개

LLM이 제공하는 안내의 표현, 신뢰도와 영향력, 탐색 순서를 중심으로 담당한다.

| ID | 방법 | 구분 | 최초 실험자 | 출처 |
| --- | --- | --- | --- | --- |
| K1 | 좌표 대신 통로·우회 경로의 종류를 선택하는 LLM 안내 | 기실험 인계, 자료 확인 대기 | 승민 | 사용자 목록 10번 / gm 1·8번 관련 |
| K2 | Conformal Prediction 기반 안내 범위 보정 | 기실험 인계, 자료 확인 대기 | 승민 | 사용자 목록 4번 / gm 10번 |
| K3 | 벽을 반영한 기하학적 거리 하한 | 신규, 미착수 | — | gm 2번 |
| K4 | LLM 안내를 사용하는 FOCAL 탐색 | 신규, 미착수 | — | gm 3번 |
| K5 | MHA*와 Thompson Sampling을 이용한 탐색 예산 배분 | 신규, 미착수 | — | gm 4번 |
| K6 | Adaptive Waypoint Weighting | 신규, 미착수 | — | sm 개선 후보 |

1. **K1 통로·우회 종류 선택:** 프로그램이 만든 통로와 연결 정보를 바탕으로 LLM이 우회 방식의 우선순위를 정한다. 실제 좌표 경로는 탐색기가 계산한다. 승민의 기존 결과를 인계받아 어떤 통로 표현과 경로 다양성을 구현했는지 확인한다.
2. **K2 Conformal Prediction:** 별도 보정 자료로 후보 선택 기준을 정하고 불확실한 안내의 범위를 넓힌다. 승민의 구현에서 실제 통계적 보정이 수행됐는지, 평가 자료가 분리됐는지 확인한다. 단순 임계값 조절을 conformal 보장으로 표현하지 않는다.
3. **K3 기하학적 하한:** 벽 때문에 필요한 최소 우회 거리를 계산해 기본 휴리스틱을 강화한다. 하한의 정확성과 추가 계산 비용을 확인한다.
4. **K4 FOCAL:** 허용된 비용 범위 안에서 LLM 안내에 따라 후보 순서를 정한다. 승민의 TransPath에서 FOCAL을 사용했더라도, 이 항목은 추가 학습 모델 없이 LLM 안내를 사용하는 구조를 독립적으로 평가하는 범위다.
5. **K5 MHA*와 Thompson Sampling:** 여러 안내 큐를 유지하고 실제 탐색 진전에 따라 확장 기회를 배분한다. 기본 탐색의 보장 조건과 모든 큐의 총비용을 확인한다.
6. **K6 적응형 가중치:** waypoint 품질이나 탐색 상황에 따라 `f=g+h+α·d(n,t)`의 안내 영향력을 조절한다. 목표에서 일시적으로 멀어지는 올바른 우회를 무조건 나쁜 안내로 처리하지 않는다.

K1·K2는 신규로 다시 만드는 대신 기존 구현과 결과를 먼저 인계받는다. K3~K6은 각 방법의 효과를 구분해 평가하고, 결합 실험은 개별 결과를 확인한 뒤 별도 조건으로 기록한다.

## 준연 담당 6개

유효한 경로와 거리 정보를 활용하는 탐색, 기하 계산, 탐색 관리 비용을 중심으로 담당한다.

| ID | 방법 | 구분 | 최초 실험자 | 출처 |
| --- | --- | --- | --- | --- |
| J1 | CHOMP 계열 최적화로 경로 수리 | 기실험 인계, 자료 확인 대기 | 승민 | 사용자 목록 5번 / gm 11번 |
| J2 | Fast Marching 기반 거리장 안내 | 기실험 인계, 자료 확인 대기 | 승민 | 사용자 목록 6번 / gm 12번 |
| J3 | 유효한 초기 경로 상한을 이용한 가지치기 | 신규, 미착수 | — | gm 5번 |
| J4 | ALT 랜드마크 휴리스틱 | 신규, 미착수 | — | gm 7번 |
| J5 | NBS·양방향 탐색 | 신규, 미착수 | — | gm 9번 |
| J6 | OPEN 우선순위 갱신 최적화 | 신규, 미착수 | — | sm 개선 후보 |

1. **J1 CHOMP 계열 수리:** 중간점을 조정해 충돌과 불필요한 굴곡을 줄인 경로를 격자로 변환하고 다시 검증한다. 승민의 기존 수정 목적함수, 반복 횟수와 격자 변환 방식을 확인한다.
2. **J2 Fast Marching:** 장애물을 고려한 거리장을 보조 안내로 사용한다. 승민의 구현이 실제 Fast Marching인지 다른 격자 거리 계산인지 구분하고, 거리장 생성 비용을 포함해 해석한다.
3. **J3 상한 가지치기:** 유효한 격자 경로의 길이 U를 확보하고 그보다 짧아질 수 없는 후보를 제외한다. 초기 경로를 얻는 비용도 포함한다. 단순 상한 가지치기와 ARA* 전체 구현을 구분한다.
4. **J4 ALT:** 랜드마크까지의 실제 그래프 거리를 이용해 하한을 만든다. 전처리·메모리 비용과 같은 지도에서의 재사용 조건을 구분한다.
5. **J5 NBS·양방향 탐색:** 출발점과 목표점 양쪽의 frontier를 사용해 탐색한다. 최초 만남을 바로 최적 경로로 간주하지 않고 해당 알고리즘의 종료 조건을 확인한다.
6. **J6 OPEN 갱신:** waypoint 변경 시 OPEN 전체를 다시 계산하는 비용을 줄이는 lazy/incremental 갱신을 검토한다. 오래된 키를 처리하는 방식이 실제 최소 우선순위 선택을 보존하는지 확인한다. pop 수가 같아도 실행시간 개선은 별도로 보고한다.

J1·J2는 기존 자료를 먼저 인계받고, J3~J6은 신규로 담당한다. 연속 경로와 격자 경로의 비용을 섞지 않으며, 전처리와 수리에 사용한 계산을 제외한 채 성능 향상을 주장하지 않는다.

## 승민 담당 6개

아래는 사용자가 전달한 기실험 항목 중 승민이 최종 담당을 유지하는 6개다. 신규 방법을 추가 배정하지 않는다.

| ID | 방법 | 구분 | 최초 실험자 | 출처 |
| --- | --- | --- | --- | --- |
| S1 | GPT 경유점 정제 | 기실험, 자료 정리·공유 | 승민 | 사용자 목록 1번 |
| S2 | 구체적인 오류 피드백으로 경로 수정 | 기실험, 자료 정리·공유 | 승민 | 사용자 목록 2번 |
| S3 | 탐색 정체 시에만 GPT 호출 | 기실험, 자료 정리·공유 | 승민 | 사용자 목록 3번 |
| S4 | TransPath 계열 모델로 유망한 경로 영역 예측 | 기실험, 자료 정리·공유 | 승민 | 사용자 목록 7번 / gm 13번 |
| S5 | 빈 공간을 압축하는 정확한 탐색 | 기실험, 자료 정리·공유 | 승민 | 사용자 목록 8번 / gm 6번 관련 |
| S6 | 필요한 장애물만 단계적으로 반영하는 탐색 | 기실험, 자료 정리·공유 | 승민 | 사용자 목록 9번 |

1. **S1 경유점 정제:** 중복·불필요한 왕복을 제거하고 충돌 없이 직접 연결 가능한 중간점을 생략한다. 기존 V-Gate의 유효성 검사만 사용하는 대조군과 정제의 추가 효과를 구분한다.
2. **S2 오류 피드백:** 프로그램이 찾은 충돌·범위·좌표 오류와 위치를 GPT에 제공해 한 번 수정한다. 두 번째 호출 비용과 수정 전후의 결과를 함께 남긴다.
3. **S3 정체 시 호출:** 먼저 g+2h로 탐색하고 정체 조건을 만족할 때 GPT를 호출한다. 정체 판정과 기존 탐색 기록의 재사용 방식, 호출 전후의 총연산량을 설명한다.
4. **S4 TransPath 계열:** 학습한 경로 포함 가능성으로 탐색을 안내한다. 실제로 어떤 모델을 학습·사용했는지, 학습 자료와 평가 자료를 어떻게 나눴는지 명시한다. 간단한 모사 구현이면 원 TransPath 전체를 재현했다고 표현하지 않는다.
5. **S5 정확한 압축 탐색:** 합법적 격자 이동을 거시 간선으로 묶고 비용을 보존하며 복원한다. 실제 압축 방식과 보존한 경로 범위를 설명한다. 임의의 압축 구현을 JPS 또는 Subgoal Graphs의 검증 완료로 간주하지 않는다.
6. **S6 장애물 단계 반영:** 일부 장애물을 반영한 문제를 정확히 풀고, 전체 지도에서 충돌한 장애물을 추가해 반복한다. 모든 반복의 탐색 비용을 합산한다. 최적성 설명에는 각 완화 문제를 정확히 풀었다는 조건과 최종 전체 충돌 검증이 필요하다.

승민은 K1·K2·J1·J2에 해당하는 기실험 자료도 각각 규민·준연에게 전달한다. 자료 인계 후의 검토·정리·필요한 보완은 새 최종 담당자가 맡으며, 최초 구현·실험 기여는 승민으로 남긴다.

총수는 다음 기준으로 계산했다.

- 승민의 기실험 방법군: 10개.
- 그 목록과 묶이지 않은 gm 신규 후보: 2·3·4·5·7·9번, 6개.
- sm에서 확인한 추가 독립 후보: 적응형 가중치와 OPEN 갱신, 2개.
- 합계: 18개. 구성요소 제거 실험과 결합 실험은 각 담당 방법군에 부속시킨다.

기존 V-Gate, A*, g+2h와 원 LLM-A*는 공통 비교군으로 사용하며 새 담당 개수에 다시 넣지 않는다.

## 자료 인계와 완료 기준

기실험 항목을 인계받았다는 이유만으로 무조건 재실험하지 않는다. 기존 자료로 확인할 수 있는 부분을 먼저 확인하고, 구현 범위가 다르거나 필요한 비교가 빠져 있을 때 보완한다.

각 담당자는 방법별로 다음 자료를 정리한다.

- 코드 경로와 커밋, 실행 명령, 필요한 환경 및 모델 설정.
- 입력 지도·문제 목록과 seed, 사용한 프롬프트·응답 캐시, 데이터 분리 방식.
- A*·원 LLM-A*·고정 g+2h 등 공통 비교군과 비교 가능한 결과.
- 경로 유효성, 경로 길이, 연산량·저장량, 전처리·API 호출·실행시간의 집계 범위.
- 실패하거나 성능이 악화된 사례와 구현의 적용 조건.
- 최초 구현·실험자, 인계 후 검토·수정·추가 실험자 및 각자의 실제 기여.

기실험 자료가 아직 공유되지 않은 항목에는 결과 파일 경로나 수치를 만들어 넣지 않는다. 이후 이 문서에 실제 코드·결과 링크와 확인 상태를 추가한다.

방법 간 비교에서는 동일한 이동 비용·8방향 이동·선분 장애물 충돌 규칙을 사용한다. 두 브랜치의 재현 실행기나 설정이 다르면 차이를 먼저 확인하고, 서로 다른 조건의 수치만으로 우열을 정하지 않는다. 원 논문 재현 결과와 개선 실험 결과를 분리한다.

## 브랜치와 문서 범위

원격에 main이 없었으므로 `gm`의 `2e8bcc1`을 기준으로 공통 문서용 main을 생성했다. 이 분담 문서 작성은 팀 최종 구현이나 제출 보고서를 선정했다는 의미가 아니다. main에 함께 존재하는 기존 코드·결과는 gm 기반 스냅샷이며, sm의 코드를 병합한 결과가 아니다.

확인 기준은 gm `2e8bcc1`, sm `fa6d8dc`와 사용자가 전달한 기실험 목록이다. 원격에 아직 올라오지 않은 후속 코드나 문서는 확인 범위에 포함하지 않았다.
