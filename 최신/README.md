# 최신 작업 문서

2026년 10월 13일 기준으로 확정한 재현 범위와 작업 흐름을 찾는 시작점이다. 실제 LLM API를 사용한 전체 실험은 아직 수행하지 않았다.

## 읽는 순서

1. [재현 과정 설명](재현_과정_설명.md): 문제 하나가 LLM 응답, 경로, 평가 결과, Table 1로 이어지는 흐름.
2. [최신 재현·개선 계획서](../LLM-Astar_Project_Plan.md): 제출 요건, 모델 2개·14개 조건, 실험 규칙, 일정과 완료 기준.
3. [과제 지침 대응과 완료 점검](과제_지침_대응.md): AI 사용·유사성 검증의 명시 범위, 감점·추가점수 항목과 준비할 근거.
4. [코드 리뷰](../review/CODE_REVIEW.md)와 [Waypoint 문답](../review/WAYPOINT_QA.md): 구현 동작과 주의할 점.
5. [논문 리뷰](../review/PAPER_REVIEW.md): 원 방법과 논문 결과의 해석.

## 확정한 범위

- 팀원 3명이 각각 재현 전 과정을 수행한 뒤, 결과와 보고서의 완성도를 비교해 팀 제출의 기반이 될 버전을 선택한다.
- 이 작업 공간과 `gm` 브랜치에서는 사용자의 구현·실험·분석을 진행한다.
- 모델 2개, 프롬프트 3종, LLM-only/LLM-A* 두 방식과 공통 기준 알고리즘 2개를 합쳐 총 14개 조건을 평가한다.
- 모든 조건은 같은 공개 1,000개 문제를 사용한다.
- 첫 모델은 GPT-4o mini다. 두 번째 모델의 이름·버전·실행 방식은 접근성·예산 확인 후 확정한다.
- 유료 호출 전 API 접근 여부와 비용 한도를 정한다.

상세 계획서는 루트의 `LLM-Astar_Project_Plan.md`를 계속 갱신한다. 이 폴더에서는 해당 문서를 연결해 최신 내용으로 안내한다. 재현 과정 설명과 계획이 바뀌면 함께 갱신한다.
